# Timpa.com-gacor-mantap-wadidaw
Repository Project PAP Kelompok 6 Website Berita Online Timpa.com

Description
- nama webnya Timpa.com
- warna biru mewah megah mantap kode: #3299CC
- referensi dari website kompas dan Inews (kalo ada saran referensi yg lebih genjet gas aja)

Sistem pengerjaan:
1. Akan dibagi menjadi 2 team:
    - Tim Naruto: Tugasnya adalah mencari gambar dan narasi berita untuk di masukin ke dalam web nya. Beranggotakan 2 orang
    - Tim Sasuke: Tugasnya adalah melakukan pembuatan code dan pengembangannya berdasarkan assets yang telah dikumpulkan oleh tim naruto. Beranggotakan 3 orang.

Workflow setiap tim:
1. Tim Naruto
     Tim naruto akan mencari gambar" dan narasi berita yang diperlukan, bebas beritanya apa dan gambarnya apa. Kumpulkan dalam 1 folder bernama assets dan didalam folder tersebut buat lagi 2 folder baru bernama img dan teks. img berisi gambar dan teks berisi narasi berita. untuk file gambar wajib menggunakan format webP, jika mendapatkan gambar berjenis selain webP bisa di rubah di website squoosh. untuk teks narasi berita buat didalam notepad atau word lalu masukin ke folder teks di dalam assets.

2. Tim Saskeh
     Tim saskeh akan membuat kodingan nya sesuai rancangan dan spesifikasi yg diminta oleh bapak, memasukan seluruh assets yg telah dikumpulkan oleh tim naruto, dan memastikan website berjalan dengan aman sentosa. 

Catatan:
- Setiap orang wajib memilki akun github yang terhubung dengan vscode masing-masing (bagi yg belum mengetahui apa itu github, bisa ditonton penjelasannya di yutub)
- Repository akan dibuat oleh radit
- Setiap penambahan, perubahan, ataupun penghapusan wajib diunggah/push ke github agar pendokumentasian lebih tertata rapi dan meminimalisir kebingungan dan kesalahpahaman antar anggota.


Bismillah. One day or Day One. Kelompok 6 timpa teks gacor mantap berkah dunia dan akhirat dapat nilai A langsung wisuda kerja jadi boss muda financial freedom. TAKBIR!!!
